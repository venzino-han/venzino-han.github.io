**역할:** 학부 2학년 구성원들을 중심으로 한 팀의 프로젝트 리드 — 핵심 기술 방향과 평가 기준을 설계하고, 코드 리뷰와 실험 결과를 통해 빠르게 피드백하는 역할에 집중했습니다.

#### 문제

짧은 기간 안에 문항 분석, 학생 행동 시뮬레이션, 데이터 생성 및 평가까지 구현해야 했고, 팀은 경험이 많지 않은 소수 인원이었습니다.

#### 접근

- 구성원 개개인이 AI를 적극 활용해 빠르게 학습하고 실행할 수 있는 **'AI Native' 방식의 조직**을 만드는 것을 목표로 했습니다.
- 프로젝트를 데이터 구축, 모델 개발, 실험·평가 등 **독립적으로 검증 가능한 단위**로 나누고, 각 구성원이 명확한 산출물을 책임지도록 했습니다.
- LLM 기반 코딩·리서치 도구를 적극 활용하되, AI가 생성한 결과를 그대로 쓰지 않고 **요구사항 정의 → 구현 → 테스트 → 검증**으로 이어지는 작업 흐름을 만들었습니다.
- 연구 산출물이 데이터와 로그 형태로만 존재하면 팀원과 고객사 모두 결과를 이해하는 데 오랜 시간이 걸린다는 문제가 있어, AI 도구로 데이터·모델 출력·학생 시뮬레이션 결과·평가 결과를 직접 탐색하고 비교할 수 있는 **웹 기반 시각화·검증 도구**를 빠르게 구축했습니다.

#### 결과

- 고객사가 별도의 분석 요청 없이 직접 결과를 확인하고 구체적인 사례를 기준으로 의견을 전달할 수 있게 되어, 검증에 필요한 시간과 반복적인 커뮤니케이션 비용을 줄였습니다.
- 팀 내부에서도 실패 사례와 개선 방향을 훨씬 명확하게 논의할 수 있었습니다.
- 경험이 많지 않은 구성원들도 빠르게 독립적인 개발과 실험을 수행했고, 소수 인원으로 **LLM 기반 문항 분석과 학생 시뮬레이션 파이프라인**을 구축했습니다.

좋은 협업은 업무를 잘 나누는 것에 그치지 않고, 구성원과 고객이 결과를 빠르게 이해하고 검증할 수 있는 환경까지 설계하는 것이며, AI는 개발뿐 아니라 의사소통의 속도도 높일 수 있다는 것을 배웠습니다.
